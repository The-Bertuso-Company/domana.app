Tag: phase-2-done (df6c5b5)

## What we shipped
- 5-tab shell locked (Explore, Activity, Sell, Pro, Me)
- Primary routes mapped (tab shell + /listing/[id])
- Canonical flows defined (Search → View → Contact → Save)
- Empty & error states documented (offline, permission, no results, etc.)
- Surface patterns decided (Modals for decisive tasks; Sheets for contextual); drawers omitted for MVP
- Extras: Tab bar styled with DS tokens (light/dark)

## Why it matters
- Navigation is frozen for MVP
- Clear rules for when to use modal vs sheet
- Fewer dead ends via planned empty/error states
- Telemetry names listed for future wiring
